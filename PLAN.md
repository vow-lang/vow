# Plan: route proc_sample's result through an arena (#1639)

## Goal
Give `proc_sample()` an `__vow_proc_sample_in_arena(arena)` runtime variant and register it as a catalogued arena route, so both compilers place its String in the inferred (block/caller) region instead of the process root arena. Fixes the linear root-arena growth per `trace_sample` tick under `--perfetto`.

## Assumptions
- Complexity: Small/Medium. The runtime function and the catalogue edit are hand-written; every compiler-side table is generated by `scripts/generate_operations.py`, so Rust and self-hosted compilers get the change together without hand-editing (best guess, verified by reading the generator markers).
- No language/CLI/spec-text change: `proc_sample`'s signature, effects and docs stay identical, so `docs/spec/grammar.md`, help text and skill text need no edit. (best guess)
- `trace_sample` in `compiler/perfetto.vow` needs no source change: its `raw: String` is block-local and does not escape, so region inference picks a block region once the route exists. The `lines`/`parts` Vecs from `string_split` are already routed. Verify by running the new fixture, not by editing perfetto.vow. (best guess)
- Regression test is a `tests/run/` root-arena-delta fixture modelled on `tests/run/parse_i64_arena.vow`, not a `bench/memory` program: adding a bench program means hand-computing a `max_rss_kb` bound (CLAUDE.md forbids `run.sh --record`) and proc_sample is empty on non-Linux. (best guess)
- No ADR is added; the existing ADR text that describes `proc_sample` as an unrouted leak is updated in place to say it is resolved.

## Steps

### 1. RED: regression fixture `tests/run/proc_sample_arena.vow` [new]
- Header `// TEST: stdout "ok"`. Shape like `parse_i64_arena.vow`: helper `fn sample_len() -> u64 [io] { let s: String = proc_sample(); s.len() }` (the String must be block-local so inference can route it), warm-up call, record `memory_root_arena_bytes()`, loop 5000 calls (cost is /proc scan per call; keep iterations moderate and assert on delta rather than sum), record after, assert `delta < 64 KiB`-ish limit chosen so the unrouted version (≈55 B/call growth at 1200 calls => 69904-4112; 5000 calls ≈ 270 KB+) fails and the routed version stays flat. Compute the limit empirically from the issue's table: unrouted growth ≥ ~54 B/call, so with 5000 calls delta ≈ 270 KB; use a 64 KiB bound. Do not assert on sampled content (non-deterministic; non-Linux returns "").
- Confirm RED with the current release compiler (`VOW_CACHE_DIR=$(mktemp -d)`, `--no-verify --no-cache`), per memory note about the stale compile cache.
- Also add `("__vow_proc_sample", 0)` to the list in `vow-ir/src/region.rs` test `returned_fresh_runtime_aggregates_allocate_in_caller_region` (red until step 3 regenerates the table).

### 2. Runtime: add the arena variant
- **File**: `vow-runtime/src/lib.rs` (3560-3584).
- Extract the formatting into a small private `fn proc_sample_text() -> String` (read_proc_table + collect_proc_samples + join), then:
  - `pub unsafe extern "C" fn __vow_proc_sample_in_arena(arena: *mut VowArena) -> *mut u8 { let s = proc_sample_text(); unsafe { alloc_bytes_string(arena, s.as_bytes()) } }`
  - `pub extern "C" fn __vow_proc_sample() -> *mut u8 { let s = proc_sample_text(); unsafe { with_root_arena(|a| alloc_bytes_string(a, s.as_bytes())) } }`
- **Reuses**: `alloc_bytes_string` (4015), same layout as `__vow_stdin_read{,_in_arena}` (4338-4352). The null-arena trap is inherited from `__vow_string_new_in_arena`.

## Risks
- Binary fixed point: the generated tables change the self-hosted compiler's own routing for `trace_sample` (perfetto.vow), so Stage 1/2 bytes differ from before but must still match each other; rerun bootstrap. `FRESH_ARENA_VARIANTS` ordering follows `arena_routes` order, deterministic (no HashMap); keep the new entry placement consistent so the generated diff is minimal.
- Region soundness: `trace_sample`'s `raw` flows into `string_split(raw, ...)` only; if inference judges it escaping (it should not), the call stays on the root wrapper silently. The regression fixture asserts the block-local shape, and a perfetto smoke (`build/vowc build --perfetto ...` per `vow/tests/perfetto.rs`) should be run once.
- Fixture flakiness: /proc scan cost per call makes iteration counts matter; keep ≤5000 and assert only on root-arena delta. Skip gracefully (still "ok") on non-Linux since the empty String also allocates nothing meaningful.
- Stale compile cache can mask the RED/GREEN result: always use a fresh `VOW_CACHE_DIR`.
- Rust clippy: new `unsafe extern "C"` fn mirrors existing ones; keep `# Safety`-doc conventions the surrounding code uses (none required for `_in_arena` siblings).
- Dual-compiler rule: satisfied via the generator (both `vow-ir/src/region.rs`/shim and `compiler/ir.vow` regenerate); the runtime is shared by both.

## Out of scope
- Making `stdin_read_line` routable (it is a bounded thread-local scratch buffer; stays `none`).
- Changing `proc_sample`'s output format, adding a `proc_sample` C/verifier model, or touching `trace_sample` logic.
- Any new bench/memory program or `bench/memory/expected.toml` change.
- Refactors/formatting of generated blocks beyond what the generator emits.
