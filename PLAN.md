# Plan: `no_struct` head context so `if DEBUG {}` / `if c == Color::Red {}` parse (#1547)

## Goal
In both compilers, never treat `Name {` / `Path::Seg {` as a struct literal or brace-form enum
constructor while parsing the head of `if` / `while` / `for … in` / `match`; the `{` always opens the
body there. The printer parenthesises any struct literal that would otherwise be exposed in a head so
`parse → print → parse` stays idempotent. Complexity: Medium (2 parsers + 2 printers + spec, one
mechanism, ~8 files).

## Assumptions
- Brace-form struct literals / enum constructors in a head now need parentheses (`if (S { a: 1 }).a == 1 {}`), exactly as in Rust. Nothing in the repo does this (grep of every `*.vow` for heads with a top-level struct literal found zero hits; the implementer re-verifies with a parse sweep, Step 8). Decision: best guess (matches the issue's proposal).
- Keep the existing PascalCase guard and `looks_like_struct_literal` unchanged; they still discriminate outside heads (`let u = Unit {};`). The new flag is purely additive.
- Printer strategy: wrap the **whole head** in parens when it exposes a struct literal (one predicate, no per-site threading). Parens leave no AST node, so the re-parse yields the same AST and the second print is identical. Decision: best guess; alternative (wrap just the literal) needs a context parameter through every `print_expr_at` recursion.
- No new diagnostic/hint for the now-rejected unparenthesised head struct literal (it falls out as the existing "expected `;` or `}`"-style error). Listed under follow-ups.
- Language-design criteria: pure disambiguation, no new type-system axis, no verifier/IR/C-emitter change.

## Steps (ordered TDD slices; each = failing test first, then minimal code)

### 1. Rust parser — UPPER_CASE / enum-path empty-block heads (red → green)
- **Test** (`vow-syntax/src/parser/expr.rs` tests, next to `lowercase_identifier_head_before_an_empty_block_parses_in_every_form`): for each of `if DEBUG { }`, `if DEBUG { } else { }`, `while FLAG { }`, `for _i in ITEMS { }`, `match MODE { }`, `if c == Color::Red { }`, `if c == Color::Red { } else { }`, `match Color::Red { }`, `while c == Color::Red { }` assert `parse_module` yields no diagnostics; for `if DEBUG { }` and `if c == Color::Red { }` additionally assert condition is `Ident("DEBUG")` / `BinaryOp{rhs: EnumConstruct{path:[Color,Red], fields: []}}` and `then_branch` is an empty block. Today these fail (the `{ }` is eaten as an empty struct / enum constructor).
- **Code**: add `no_struct: bool` to `Parser` (init `false`); add a small helper `fn with_no_struct<T>(&mut self, value: bool, f: impl FnOnce(&mut Self) -> T) -> T` (save, set, run, restore — restore must run on every path, so no `?` inside the closure). Gate both brace-consumption sites with `!self.no_struct`: `parse_prefix` `Ident` arm (`expr.rs:244`) and `parse_enum_construct` brace arm (`expr.rs:711`). Wrap the head expression in `parse_if_expr`, `parse_while_expr`, `parse_for_expr` (iterable), `parse_match_expr` (scrutinee) with `with_no_struct(true, …)`. Also parse `else if` chain through `parse_if_expr` as today (each `if` sets its own head context).

### 2. Rust parser — context is cleared inside delimiters (red → green)
- **Test**: all must parse clean *and* produce the struct literal / enum constructor node: `if f(S { a: 1 }) { }`, `if g(Shape::Circle { r: 1 }) { }`, `if (S { a: 1 }).a == 1 { }`, `if v[S { a: 1 }.a] == 1 { }`, `if { let s = S { a: 1 }; s.a == 1 } { }`, `if match x { _ => S { a: 1 }.a == 1 } { }` (match arms clear), `if loop vow { invariant: S { a: 1 }.a == 1 } { break true; } { }` (the vow block sits *inside* a head, so this actually exercises the clear in `parse_vow_block`); regression: outside heads still literal — `let p = S { a: 1 };`, `if c { S { a: 1 } } else { S { a: 2 } }`, `match x { A => S { a: 1 }, }`, `Unit {}`. Negative: `if S { a: 1 }.a == 1 { }` now reports a diagnostic (pin that it is an error, not a silent mis-parse).
- **Coverage rule (codecov/patch is a blocking 95% gate and only Rust tests count)**: every save/restore site gets its own Rust test, one per case above — paren, tuple, call args, method-call args, index, block, vow block, match arms — and every arm of the printer predicate in Step 4 gets one Rust printer test.
- **No array literals**: the issue lists "array literals" among the clearing contexts, but neither parser has an array-literal form (`[` is only an index postfix; `parse_prefix` has no `LBracket` arm), so that item is not applicable — do not add one.
- **Code**: set `no_struct = false` (save/restore) in: `parse_paren_or_tuple` (`expr.rs:353`, covers tuples), `parse_call_args` (`expr.rs:488`, covers calls + method calls + brace-less enum ctor args), the `LBracket` arm of `parse_postfix` (`expr.rs:442`), `parse_block` (`mod.rs:521`; it uses `?`, so rename the existing function in place by changing only its signature line to `parse_block_body` and add a thin `parse_block` wrapper beside it: `let saved = replace(&mut self.no_struct, false); let r = self.parse_block_body(); self.no_struct = saved; r` — do not move or re-indent the body, which would count as new uncovered lines for codecov/patch), `parse_vow_block` (`mod.rs:453`), and the match arm list (after `expect(LBrace)` in `parse_match_expr`, restore before returning). `return`/`break` values, `=` RHS and binary operands intentionally inherit the flag.

### 4. Printers — parenthesise exposed struct literals in heads (red → green)
- **Test (Rust)** in `vow-syntax/src/printer.rs` tests: for each source below, assert `parse(print(parse(src)))` has the same AST as `parse(src)` and print is a fixed point (assert on the round-trip and on the head being parenthesised, not on how an empty block is spelled): `if (S { a: 1 }).a == 1 { }`, `while (S { a: 1 }).a == 1 { }`, `for i in (S { items: v }).items { }`, `match (S { a: 1 }) { }`. One test per predicate arm: BinaryOp lhs and rhs, UnaryOp (`!(S{..}.b)`), Question, FieldAccess, MethodCall receiver, Call callee, Index base, Assign, Break, Return. Negative (printed text has no head-level extra parens): `if f(S { a: 1 }) { }` (call arg), `if v[S { a: 1 }.a] == 1 { }` (index expr), `if (S { a: 1 }, 2).1 == 2 { }`-style tuple, `if { S { a: 1 }.a == 1 } { }` (block); `let s = S { a: 1 };` and `if c { S { a: 1 } } else { S { a: 2 } }` unchanged.
- **Code (Rust)**: `fn head_exposes_struct_literal(e: &Expr) -> bool` that returns true for `StructLiteral` and recurses through exactly the un-delimited positions: `BinaryOp` (both sides), `UnaryOp` operand, `Cast` expr, `Question` expr, `FieldAccess` base, `MethodCall` receiver (not args), `Call` callee (not args), `Index` base (not index), `Assign` lhs/rhs, `Break`/`Return` value. **Decision (pinned identically for Rust and Vow):** the predicate is a deliberate over-approximation — it does not model the parens the printer already adds around some operands (`print_postfix_base` for BinaryOp/UnaryOp/Assign/Break/Return bases, `Cast` for a non-atom operand). A head like `(S { a: 1 }) as i64 == 1` therefore prints as `if ((S { a: 1 }) as i64 == 1) { }` — redundant but round-trips and is deterministic. Do not special-case it; both printers must implement the identical arm list. Everything else (`Tuple`, `Block`, `If`/`While`/`ForEach`/`Match`/`Loop` — which wrap their own heads — literals, idents, `EnumConstruct`, which always prints in paren form) is `false`. Add `fn print_head(expr, level)` = parens iff the predicate holds, and use it for the `If` condition, `While` condition, `ForEach` iterable and `Match` scrutinee.
- **Test + code (Vow)**: extend `tests/fixtures/contracts/contract_text_postfix.vow` with clauses whose `if` head exposes a struct literal (needs a small `struct Pt { a: i64 }` declared in the fixture; confirm the `contracts` command does not require the clause to type-check beyond what the existing `Shape` enum usage requires), add the canonical text lines to `contract_text_postfix.expected`, and the same canonical clauses to `contract_text_postfix_canonical.vow` (shares the expected file, proving idempotence). Implement `head_exposes_struct_literal_text(a, eid)` in `compiler/contract_text.vow` over arena tags (`EXPR_SLIT` → true; recurse through `EXPR_BINOP`/`EXPR_UNOP`/cast/question/field/method-recv/call-callee/index-base/assign/break/return; confirm operand slots via `expr_a/b/c` in `compiler/ast.vow:188`) and use it in the `EXPR_IF` / `EXPR_MATCH` / `EXPR_WHILE` / `EXPR_FOR` branches of `print_control_expr_text` (`contract_text.vow:369-420`). Rust and Vow outputs must be byte-identical (checked by `scripts/full_test.sh` contract-text parity loop).

## Risks
- **Behaviour change**: previously accepted `if S { a: 1 }.a == 1 {}` / `match S { a: 1 } {}` / brace-form enum constructors in heads now fail. Mitigation: corpus sweep (Step 8) + bootstrap, which parses all of `compiler/`; spec states the rule.
- **Flag leaks on error paths** (`?` in Rust `parse_block`, `parser_abort` in Vow): a stuck `no_struct = true` would silently break later literals. Mitigation: `parse_block` wrapper pattern; recovery tests (Step 2/3 negative cases followed by a valid literal in the same module).
- **Printer/parser disagreement**: if the exposed-position predicate misses a position, `print` emits an unparenthesised literal that re-parses differently, breaking `parse → print → parse`. Mitigation: predicate mirrors the parser's un-delimited positions exactly; canonical twin fixture checks idempotence in both compilers.
- **Rust/Vow printer drift**: contract text must be byte-identical; guarded by the parity loop in `full_test.sh` (~line 2138).
- **Binary fixed point**: parser behaviour change only; compiler sources contain no head struct literals, so stage-1/2 outputs stay identical; verify with bootstrap on the final SHA. No `HashMap`/ordering/stack-slot impact.
- **Clippy `--all-targets`**: closure helper must not trip `redundant_closure`/`type_complexity`; keep it a plain generic method.
- **Pre-existing flakes** (see memory): `vow` e2e SKIP-panic tests and `concrete-block-region-parity` reproduce on clean main — verify against clean `origin/main` before blaming this change.
