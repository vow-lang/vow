# Spec parts

`docs/spec/cli.md`, `grammar.md`, `errors.md` and `contracts.md` are generated by
`scripts/spec_assemble.py` as the byte-exact concatenation of the files in
`docs/spec/src/<doc>/`, in file-name order. Edit the parts, never the assembled file.

- `python3 scripts/spec_assemble.py` rewrites the assembled files.
- `python3 scripts/spec_assemble.py --check` fails when one is stale or a part is over 20,000 bytes
  (the pre-commit hook and CI run it).
- `python3 scripts/spec_assemble.py --import` ports an edit already made to an assembled file into
  its parts.
- `python3 scripts/spec_assemble.py --split docs/spec/src/cli/020-x.md` halves an oversized part.

A part may begin with a blank line, because a cut falls before the blank line that separated two
sections; it must not end with one, or the whitespace hooks would rewrite it.
